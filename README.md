# JavaScript Password Generator 🔐

Bu proje, kullanıcıların güçlü ve rastgele şifreler oluşturmasını sağlar. 

## Özellikler
- Şifre uzunluğu ayarlanabilir
- Büyük harf, küçük harf, rakam, sembol ve boşluk seçenekleri
- Tekrar eden karakterleri engelleme seçeneği
- Şifre gücünü renge göre gösterme
- Tek tıkla kopyalama

## Kullanım
1. `index.html` dosyasını tarayıcınızda açın
2. Uzunluğu ve karakter seçeneklerini belirleyin
3. "Generate Password" butonuna tıklayın
4. Şifreyi kopyalamak için kopyalama ikonuna tıklayın
